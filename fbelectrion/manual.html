Instructivo de Conexiones – Sistema de Riego Automático

Este instructivo describe cómo conectar correctamente el sensor de humedad, el sensor de lluvia y la válvula, siguiendo el esquema presentado.

⚠️ Alimentación

IMPORTANTE: Todo el sistema debe alimentarse con 5V.

🌱 1. Sensor de Humedad del Suelo

- Enterrar el sensor en un punto elevado del terreno.
- Conectar los cables del sensor de la siguiente manera:

  • GND del sensor → borne G
  • Salida analógica del sensor → borne A

🌧️ 2. Sensor de Lluvia

- Colocar en un punto elevado para evitar salpicaduras.
- Conexiones:

  • GND → borne G
  • Señal (cable amarillo) → borne 0
  • 5V → borne 3

⚡ 3. Alimentación del Módulo

- Ingresar 5V a través de los bornes:

  • + → 5V
  • G → GND

💧 4. Válvula de Riego

- Conectar uno de los polos de la válvula en los bornes indicados:

  • R = salida hacia la válvula
  • El otro polo de la válvula conecta a la alimentación necesaria según el modelo de la válvula.

📌 Resumen de Bornes

  • G → Tierra/GND
  • A → Sensor de humedad (analógico)
  • 0 → Señal de sensor de lluvia
  • 3 → 5V para sensor de lluvia
  • + → Entrada de alimentación 5V
  • R → Salida a la válvula
