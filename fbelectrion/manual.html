Instructivo de Conexiones del Sistema de Riego

IMPORTANTE: Alimentar todo el sistema con 5V.

1. Sensor de Humedad del Suelo

Colocar el sensor enterrado en un punto elevado del terreno. Conectarlo de la siguiente manera:

  • GND del sensor → borne G
  • Salida analógica → borne A

2. Sensor de Lluvia

Instalar el sensor en una zona elevada y despejada. Conexiones:

  • GND → borne G
  • Señal (cable amarillo) → borne 0
  • 5V → borne 3

3. Alimentación del Módulo

Conectar la alimentación principal de 5V en:

  • + → 5V
  • G → GND

4. Conexión de la Válvula

La salida hacia la válvula de riego se realiza desde los bornes:

  • R → un polo de la válvula
  • El otro polo se conecta según la alimentación requerida por la válvula.

Resumen de Bornes

  • G → Tierra / GND
  • A → Señal analógica del sensor de humedad
  • 0 → Señal del sensor de lluvia
  • 3 → 5V para sensor de lluvia
  • + → Entrada de alimentación 5V
  • R → Salida a la válvula

Esquema Visual

Referencia gráfica de las conexiones:

  1. Sensor de humedad del suelo (2 cables):
    • Cable rojo → Conectar a GND del equipo.
    • Cable blanco → Conectar a A0 (entrada analógica).
    Este sensor debe enterrarse en un punto elevado del suelo.
  2. Sensor de lluvia capacitivo (3 cables):
    • Cable negro → GND
    • Cable rojo → +5V
    • Cable amarillo → GPIO 0 (entrada digital)
    Colocarlo en una zona elevada para evitar falsas detecciones.
  3. Alimentación del sistema:
    • Cable rojo → +5V IN
    • Cable negro → GND
    IMPORTANTE: alimentar con una fuente estable de 5 V.
  4. Conexión a la válvula de riego:
    Dentro del equipo hay un relé. Por eso, se debe **interceptar solo uno de los dos cables que alimentan la válvula**:

    • Cable azul (1) → entra al relé (tornillo R1).
    • Cable azul (2) → sale del relé hacia la válvula (tornillo R2).

    El otro cable ORIGINAL de la válvula queda **sin cortar**, tal como viene.
