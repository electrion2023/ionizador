Crear Script de Google

Este script se ejecuta automáticamente cada hora y obtiene datos del clima.

Ir a Google Script
📝 Instrucciones:
  1. Haz clic en "+ Nuevo proyecto"
  2. Borra todo el código existente
  3. Copia y pega el siguiente código:
// SISTEMA CLIMA ESP8266 - ACTUALIZACIÓN AUTOMÁTICA const FIREBASE_URL = "https://pronosticos-761a3-default-rtdb.firebaseio.com"; function actualizarClimaAutomatico() { console.log('🔄 Actualizando clima...'); try { const url = 'https://api.open-meteo.com/v1/forecast?latitude=-33.295498&longitude=-66.338036&hourly=precipitation_probability&forecast_hours=2&timezone=auto'; const response = UrlFetchApp.fetch(url); const datos = JSON.parse(response.getContentText()); const datosESP = { prob: datos.hourly.precipitation_probability[0], prob2: datos.hourly.precipitation_probability[1], hora: datos.hourly.time[0].substring(11, 16), actualizado: new Date().toLocaleString("es-AR") }; const opciones = { method: 'PUT', contentType: 'application/json', payload: JSON.stringify(datosESP) }; UrlFetchApp.fetch(FIREBASE_URL + "/clima.json", opciones); console.log('✅ Enviado a Firebase'); } catch (error) { console.log('❌ Error: ' + error); } } function probar() { console.log('🧪 Prueba manual'); actualizarClimaAutomatico(); return "Prueba OK"; } function activarAutomatico() { const triggers = ScriptApp.getProjectTriggers(); triggers.forEach(t => ScriptApp.deleteTrigger(t)); ScriptApp.newTrigger('actualizarClimaAutomatico') .timeBased() .everyHours(1) .create(); console.log('✅ Programado cada hora'); return "¡Activado!"; }
💡 Nota: Guarda el script como "ClimaESP8266_Simple"

Configurar Firebase

Base de datos en tiempo real para almacenar los datos del clima.

Ir a Firebase
🔥 Configuración:
  1. Crea un nuevo proyecto
  2. Activa "Realtime Database"
  3. Configura las reglas de seguridad:
{ "rules": { ".read": true, ".write": true } }
🔒 Seguridad: Estas reglas son para desarrollo. En producción, usa autenticación.
✅ Tu URL de Firebase:
https://pronosticos-761a3-default-rtdb.firebaseio.com/clima.json
3

Código ESP8266

Programa que se ejecuta en el microcontrolador para leer datos.

📦 Librerías necesarias:
  • Firebase ESP8266 Client (por Mobizt)
  • ArduinoJson (por Benoit Blanchon)
#include #include // CONFIGURAR ESTOS DATOS const char* WIFI_SSID = "TU_WIFI"; const char* WIFI_PASSWORD = "TU_PASSWORD"; #define FIREBASE_HOST "pronosticos-761a3-default-rtdb.firebaseio.com" FirebaseData fbData; void setup() { Serial.begin(115200); // Conectar WiFi WiFi.begin(WIFI_SSID, WIFI_PASSWORD); while (WiFi.status() != WL_CONNECTED) { delay(500); Serial.print("."); } Serial.println("\n✅ WiFi conectado"); // Conectar Firebase Firebase.begin(FIREBASE_HOST); Serial.println("✅ Firebase conectado"); } void loop() { if (Firebase.getInt(fbData, "/clima/prob")) { int probabilidad = fbData.intData(); Serial.print("🌧️ Probabilidad: "); Serial.print(probabilidad); Serial.println("%"); if (probabilidad > 50) { Serial.println("⚠️ Alta probabilidad de lluvia!"); } } else { Serial.println("Error: " + fbData.errorReason()); } delay(300000); // Esperar 5 minutos }
⚙️ Configuración: Reemplaza "TU_WIFI" y "TU_PASSWORD" con tus datos reales.
4

Activar Sistema

Pasos finales para poner en marcha el sistema completo.

🎯 Secuencia de activación:
  1. En Google Script, ejecuta activarAutomatico()
  2. Luego ejecuta probar() para primera carga
  3. Verifica en Firebase que hay datos
  4. Sube el código al ESP8266
  5. Abre el Monitor Serial (115200 baudios)
✅ Verificación:

Para verificar que todo funciona:

  • Google Script: Ver → Logs
  • Firebase: /clima.json
  • ESP8266: Monitor Serial

Solución de Problemas

Problemas comunes y cómo solucionarlos.

🔧 Problema: Error 404 en Firebase

Solución: Verifica que la URL sea correcta y que las reglas permitan escritura.

📶 Problema: ESP8266 no se conecta a WiFi

Solución: Verifica credenciales WiFi y distancia al router.

🔄 Problema: No se actualiza automáticamente

Solución: En Google Script, verifica que hay triggers activos.

📊 Monitoreo:

El sistema se mantiene automático. Puedes cerrar todo y seguirá funcionando.
